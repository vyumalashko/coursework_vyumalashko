# Оптимизация кредитных решений на основе машинного обучения и экономической функции прибыли

Репозиторий с кодом и результатами курсовой работы.

В работе исследуется, при каких условиях экономический (profit-driven)
критерий отбора кредитного портфеля превосходит риск-ориентированный, и
как структура данных Lending Club (цензурирование незрелых винтажей,
смещение отбора) влияет на корректность оценки. Анализ выполнен по
фактическим денежным потокам с контролем зрелости винтажей.

## Структура репозитория

    notebooks/        — ноутбук с полным пайплайном экспериментов
    data/             — описание данных и инструкция по их получению

    README.md         — этот файл

## Основные результаты

  На свежих, ещё не дозревших винтажах
  реализованная доля потерь тела долга мнимо растёт; на дожитых до
  конца срока кредитах она стабильна (~0,50). Это согласуется с
  цензурированием и исчезает после контроля зрелости. Бэктест
  profit-политик без такого контроля систематически смещён.
  При ограничении капитала преимущество отбора по ожидаемой 
  прибыли на доллар над отбором по вероятности дефолта неустойчиво 
  между винтажами: на тестах 2013–2014 оно значимо (до +12,9 млн 
  при бюджете 30 %), а на тесте 2015 исчезает и при большом бюджете 
  обращается. Причина — недооценка риска в верхнем сегменте ставок 
  винтажа 2015. Преимущество контингентно качеству ценообразования 
  платформы.
  Градиентный бустинг и логистическая регрессия
  практически эквивалентны по ранжированию (TOST ±0,005 AUC).
  Параметрическая функция прибыли неустойчива к ненаблюдаемым
  допущениям и пригодна только для упорядочения заявок, не для
  оценки абсолютного уровня прибыли.

Подробности и доверительные интервалы — в Главе 3 курсовой.

## Ограничения

Выводы относятся к дооптимизации уже одобренной платформой популяции
P2P-кредитов в США в фазе посткризисного роста 2012–2015 годов.
Перенос на банковские портфели, другие страны или фазу спада требует
отдельной проверки.
