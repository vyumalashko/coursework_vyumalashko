# Данные

В работе используется открытый датасет Lending Club — крупнейшей в США
платформы P2P-кредитования. Сам файл данных в репозиторий не включён
из-за размера и условий распространения Kaggle; его нужно скачать
отдельно.

## Источник

Lending Club Loan Data (2007–2018Q4), Kaggle:
https://www.kaggle.com/datasets/wordsforthewise/lending-club

Нужный файл: `accepted_2007_to_2018Q4.csv` (~1,5 ГБ, ~2,26 млн строк).

## Куда положить

После скачивания файл должен лежать по пути:

    data/accepted_2007_to_2018Q4.csv

Именно этот путь захардкожен в ноутбуке (переменная `DATA` в Блоке 0).

## Краткое описание

Каждая строка — один кредит, выданный платформой в период 2007–2018.
Доступны: сумма кредита, годовая ставка, срок (36/60 мес.), кредитный
рейтинг платформы (grade/sub_grade), характеристики заёмщика на момент
заявки (доход, FICO, DTI, кредитная история) и пост-факт поля
(фактические платежи, взыскания, итоговый статус).

## Процедура подготовки (кратко)

1. Загружаются только поля, нужные модели и денежной метрике
   (список — в ноутбуке, переменная `NEEDED`).
2. Отбираются записи с непустым `loan_status`, корректной датой выдачи
   и положительным платежом.
3. Дата среза для расчёта зрелости: 2018-12-31.
4. Целевая переменная: дефолт (Charged Off / Default) в первые 36
   месяцев на книге.
5. Для денежного анализа дополнительно фильтруются «дозревшие» кредиты
   (mob ≥ term), чтобы исключить цензурирование незрелых винтажей.

Подробности — в Главе 2 курсовой и в комментариях к ячейкам ноутбука.
